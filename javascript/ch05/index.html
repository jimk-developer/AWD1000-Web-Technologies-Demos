    4. Timed Commands

    setInterval() + clearInterval() - Mission Clock

    The clock uses setInterval() to update every second. clearInterval() pauses it. The timer ID returned by setInterval() must be saved to a variable - it's the only way to stop the timer later.

    00:00:00

    setTimeout() + clearTimeout() - Incoming Signal

    setTimeout() fires once after a delay. clearTimeout() cancels it if clicked before the delay expires. This contrasts with setInterval(), which repeats indefinitely.

    No signal scheduled.
