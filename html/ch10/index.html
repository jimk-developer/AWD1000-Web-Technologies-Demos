CSS Transforms styles.css

The transform property changes an element's shape, position, or size without affecting the surrounding layout. Hover over each card to see the transform applied. A transition on the card makes the change smooth.

↔

translate()

Moves the element horizontally, vertically, or both.

transform: translateX(10px)
⤢

scale()

Resizes the element. Greater than 1 enlarges; less than 1 shrinks.

transform: scale(1.08)
↻

rotate()

Rotates clockwise. Negative degrees rotate counter-clockwise.

transform: rotate(6deg)
⟋

skew()

Tilts the sides of the element along the X or Y axis.

transform: skewX(8deg)
