Designing for Mobile Devices

Resize your browser window (or open the device toolbar in DevTools) and watch this page rearrange itself. One set of HTML and CSS, every screen size.

Mobile-First Strategy

This page is built mobile-first (concept #2). The base CSS describes the phone layout. Larger screens are handled later with @media (min-width: ...) blocks that add styling. We never write desktop styles and then fight to shrink them down.

Fluid Layout & Media Queries

The cards below are one column on a phone, two on a tablet, and three on a desktop. Same markup — the breakpoints do the work.

320–480px

Phones. This is our base layout: a single column, no horizontal scrolling.

768px+

Tablets. The first min-width breakpoint gives us two columns.

1024px+

Laptops and desktops. A second breakpoint expands us to three columns.

Relative Units

Everything sized on this page leans on relative units (concept #3): rem for type and spacing, % for widths, and a touch of vw. The pill below uses border-radius: 999px to look fully rounded (concept #11).
