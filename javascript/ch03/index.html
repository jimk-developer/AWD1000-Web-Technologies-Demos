4. Loops — The Loop Lab

while Loop (pretest) — Credit Drain

A while loop checks its condition BEFORE each iteration. If the starting value is already falsy, the loop body never runs at all.

do...while Loop (posttest) — Prize Wheel

A do...while loop runs its body FIRST, then checks the condition. The body executes at least once even if credits are already 0.

for Loop — Leaderboard Builder

A for loop keeps init, condition, and update together in one line. insertAdjacentHTML("beforeend", ...) adds each item without replacing what's already in the list.

    Nested for Loop — 2D Cabinet Grid

    The outer loop walks the rows, the inner loop walks each column within that row. The inner loop completes all its iterations for every single outer iteration.

    7. switch Statement — Game Mode & Arcade Hours

    Basic switch (with break)

    A switch compares one expression against multiple case labels. Each break exits the switch after the matching case runs.

    Intentional Fallthrough — Arcade Hours

    Omitting break deliberately lets two or more case labels share the same code. Always leave a comment so future readers know it's intentional.

    8. Loop Control — break, continue & Labels

    break — Stop When Found

    break exits the loop immediately when the target is found, without scanning the remaining elements.

    continue — Skip Undefined Slots

    continue skips the rest of the current iteration and jumps straight to the next one, without exiting the loop entirely.

    Labeled Loop — Break Out of Both Loops at Once

    A label names an outer loop so a break labelName inside a nested loop can exit BOTH loops at the same time, not just the inner one.
